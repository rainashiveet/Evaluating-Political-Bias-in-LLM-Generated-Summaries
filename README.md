# Python-Based NLP Evaluation Pipeline for LLM Summary Quality and Political Bias Analysis

## Project Title

**Evaluating Political Bias in LLM-Generated Summaries: Evidence from Reddit Discourse During India’s 2024 General Election**

---

## Overview

This project is a Python-based Natural Language Processing evaluation pipeline that analyzes whether Large Language Models introduce political bias while summarizing Reddit discussions related to India’s 2024 Lok Sabha General Election.

Large Language Models are now commonly used to summarize news articles, social media discussions, political debates, and online content. However, in political contexts, summarization is not only about reducing text length. A good political summary should also preserve the original meaning, emotional tone, and neutrality of the discussion.

This project evaluates summaries generated by six Large Language Models and checks them across three major dimensions:

1. Summary quality
2. Sentiment preservation
3. Political fairness

The project compares LLM-generated abstractive summaries with BERT-based extractive reference summaries using evaluation metrics such as ROUGE, BLEU, BERTScore, TextBlob sentiment polarity, VADER sentiment, sentiment shift, and entity-level political sentiment analysis.

---

## Main Research Question

The main research question of this project is:

> Do Large Language Models exhibit political bias while summarizing Reddit discussions related to India’s 2024 Lok Sabha General Election?

The project answers this by checking:

- Whether summaries preserve the important content
- Whether summaries change the emotional tone
- Whether summaries treat political entities differently
- Whether model quality and model fairness are aligned or different

---

## Why This Project Matters

Political content is sensitive because even a small change in wording can affect how readers interpret political leaders, parties, policies, or election events.

For example, if the original Reddit discussion is neutral but the AI-generated summary becomes more negative toward one political leader and more positive toward another, then the summary may introduce political bias.

Therefore, political summarization should be evaluated not only for accuracy, but also for fairness and neutrality.

The main idea of this project is:

> A model can summarize well, but that does not automatically mean it summarizes fairly.

Extractive Summary

An extractive summary selects important sentences directly from the original text.

It does not rewrite the text creatively. It chooses important sentences from the source.

Example

The election campaign focused on unemployment, development, leadership, and voter turnout. Many Reddit users discussed the role of national parties and regional alliances.

Extractive summary:

The election campaign focused on unemployment, development, leadership, and voter turnout.

The sentence is taken directly from the original text.

Why BERT Extractive Summary Was Used

Human-written reference summaries were not available for every Reddit post. Therefore, BERT-based extractive summaries were used as benchmark summaries.

BERT extractive summaries were useful because:

They preserved original source information.
They avoided adding new information.
They provided a consistent reference for all models.
They helped compare LLM outputs fairly.

Important note:

BERT was not trained in this project.
It was used as an existing tool/model for creating reference summaries and for semantic evaluation.

The discussion mainly highlighted election issues such as jobs, development, leadership, and voter participation.

The meaning is similar, but the wording is different.

If each model received a different prompt, then the comparison would become unfair because the results could depend on the prompt instead of the model.

Therefore, the same prompt structure was used for all LLMs.

Evaluation Metrics

This project uses multiple evaluation metrics because no single metric can fully judge summary quality and fairness.

The metrics are divided into three groups:

Summary quality metrics
Sentiment metrics
Political fairness metrics
1. ROUGE

ROUGE stands for:

Recall-Oriented Understudy for Gisting Evaluation

ROUGE is commonly used for summarization evaluation.

It checks word overlap between the reference summary and the generated summary.

In this project, ROUGE compares:

BERT extractive reference summary
vs
LLM-generated abstractive summary

The code uses:

ROUGE-1
ROUGE-2
ROUGE-L
ROUGE-1

ROUGE-1 measures unigram overlap.

A unigram means one word.

Example

Reference:

Modi won the election

Generated:

Modi won the campaign

Reference unigrams:

Modi
won
the
election

Generated unigrams:

Modi
won
the
campaign

Common words:

Modi
won
the

ROUGE-1 checks this single-word overlap.

ROUGE-2

ROUGE-2 measures bigram overlap.

A bigram means two continuous words.

Example

Sentence:

Modi won the election

Bigrams:

Modi won
won the
the election

ROUGE-2 is stricter than ROUGE-1 because the exact two-word sequence must match.

ROUGE-L

ROUGE-L measures the longest common subsequence.

It checks the longest sequence of words that appears in the same order in both summaries.

Example

Reference:

Modi won the election after campaign

Generated:

Modi won after rally

Common sequence:

Modi won after

ROUGE-L captures sequence-level similarity.

ROUGE Precision, Recall, and F1

ROUGE gives:

Precision
Recall
F1/F-measure

In this project, the code uses F-measure.

Precision

Precision answers:

Out of what the model generated, how much matched the reference?

Formula:

Precision = Matching Content / Generated Content
Recall

Recall answers:

Out of the reference content, how much was captured by the generated summary?

Formula:

Recall = Matching Content / Reference Content
F1 / F-measure

F1 balances precision and recall.

Formula:

F1 = 2 × Precision × Recall / (Precision + Recall)

F1 is useful because precision alone or recall alone can be misleading.

2. BLEU

BLEU stands for:

Bilingual Evaluation Understudy

BLEU was originally designed for machine translation, but it can also be used for summarization evaluation.

BLEU is precision-oriented.

It asks:

Out of what the model generated, how much matched the reference?
N-Gram in BLEU

An n-gram is a continuous sequence of n words.

Example Sentence
Modi won the election
1-Gram / Unigram
Modi
won
the
election
2-Gram / Bigram
Modi won
won the
the election
3-Gram / Trigram
Modi won the
won the election

BLEU checks how many generated n-grams match the reference n-grams.

Why BLEU Scores Are Usually Low in This Project

The project compares:

BERT extractive summary
vs
LLM abstractive summary

The BERT extractive summary often uses original wording.

The LLM abstractive summary may use different wording.

Example

Reference:

The party won the election.

Generated:

The party secured victory in the polls.

The meaning is similar, but the words are different.

Therefore, BLEU may give a low score because it depends on exact n-gram overlap.

BLEU Smoothing

BLEU can become zero when exact higher-order n-gram matches are missing.

To avoid this, the code uses smoothing:

SmoothingFunction().method1

Smoothing makes BLEU more stable for short summaries.

3. Difference Between BLEU and ROUGE
Point	BLEU	ROUGE
Main focus	Precision	Recall/content coverage
Original use	Machine translation	Summarization
Main question	How much generated text matched the reference?	How much reference content was captured?
Penalizes	Extra or incorrect generated phrases	Missing important reference content
Works on	N-gram precision	N-gram/content overlap

Simple memory trick:

BLEU = Generated text correctness
ROUGE = Reference content coverage
4. BERTScore

BERTScore measures semantic similarity.

It uses contextual embeddings from transformer models.

Unlike ROUGE and BLEU, BERTScore can understand meaning similarity even when exact words are different.

Example

Reference:

The party won the election.

Generated:

The party secured victory in the polls.

ROUGE and BLEU may give lower scores because the wording is different.

BERTScore can still give a high score because the meaning is similar.

BERTScore Outputs

BERTScore gives:

Precision
Recall
F1
BERTScore Precision

BERTScore Precision means:

How much of the generated summary is semantically relevant to the reference?
BERTScore Recall

BERTScore Recall means:

How much of the reference meaning is captured by the generated summary?
BERTScore F1

BERTScore F1 balances semantic precision and semantic recall.

In the code, only the average BERTScore F1 is stored for each model.

Important BERTScore Note

When BERTScore runs for the first time, it may download model files such as RoBERTa-large from Hugging Face.

You may see warnings such as:

UNEXPECTED keys
MISSING keys

These warnings can usually be ignored for BERTScore because the library is loading a pretrained model for embedding-based similarity calculation.

This does not mean that the project is training a model.

5. Length Ratio

Length ratio compares the length of the generated summary with the reference summary.

Formula:

Length Ratio = Number of words in generated summary / Number of words in reference summary
Interpretation
Length Ratio	Meaning
Less than 1	Generated summary is shorter than reference
Around 1	Generated summary length is close to reference
Greater than 1	Generated summary is longer than reference

Length ratio helps identify whether a model is over-compressing or over-expanding summaries.

6. TextBlob Sentiment

TextBlob is a Python library used for sentiment analysis.

It gives sentiment polarity.

Polarity Range
Score	Meaning
-1	Highly negative
0	Neutral
+1	Highly positive

In this project, TextBlob is used to calculate sentiment polarity for:

BERT reference summary
LLM-generated summary
7. Sentiment Shift

Sentiment shift measures how much the emotional tone changes between the reference summary and the LLM-generated summary.

Formula:

Sentiment Shift = |Reference Sentiment - Generated Summary Sentiment|
Example

Reference sentiment:

0.20

Generated summary sentiment:

-0.30

Sentiment shift:

|0.20 - (-0.30)| = 0.50

A lower sentiment shift means the model preserved the original tone better.

A higher sentiment shift means the model changed the emotional tone more.

This is important in political summarization because a change in emotional tone can create political bias.

8. VADER Sentiment

VADER stands for:

Valence Aware Dictionary and sEntiment Reasoner

VADER is a sentiment analysis tool designed for social media text.

It is useful for Reddit data because Reddit text often contains:

Informal language
Punctuation
Capitalization
Emotion-heavy expressions
Negation
Intensity markers

VADER gives four scores:

Positive
Negative
Neutral
Compound
Compound Score

The compound score is the overall sentiment score.

Compound Score	Meaning
Close to -1	Highly negative
Around 0	Neutral
Close to +1	Highly positive
9. Entity-Level Political Sentiment

Entity-level sentiment checks how the summary treats specific political entities.

In this project, the main entities checked were:

Modi
Rahul

The code checks whether the entity appears in the summary.

If the entity appears, VADER calculates the compound sentiment score for that summary.

If the entity does not appear, the function returns 0.

This helps compare whether summaries are more positive or negative toward one political leader than another.

Fairness Differential

Fairness differential measures the difference between entity sentiment scores.

Example:

Modi Sentiment = -0.0154
Rahul Sentiment = +0.0064
Difference = 0.0218

A smaller difference means more balanced treatment.

A larger difference may indicate possible political bias.

Important note:

Entity-level sentiment does not prove bias absolutely.
It provides a quantitative signal of possible bias.
10. Overall Score

The overall score combines four summary quality metrics:

ROUGE-1
ROUGE-L
BLEU
BERTScore

Formula:

Overall Score = (ROUGE-1 + ROUGE-L + BLEU + BERTScore) / 4

This score combines:

Word-level similarity
Sequence-level similarity
N-gram precision
Semantic similarity
Why Sentiment Shift Is Not Included in Overall Score

Sentiment shift measures tone preservation and fairness.

It is not a direct summary quality metric.

Therefore, sentiment shift is analyzed separately.

Why ROUGE-2 Is Not Included in Overall Score

ROUGE-2 is stricter because it checks two-word phrase overlap.

Since LLM summaries are abstractive and may use different phrasing, ROUGE-2 can penalize valid paraphrasing.

Therefore, the overall score uses ROUGE-1, ROUGE-L, BLEU, and BERTScore for a balanced evaluation.

Key Findings
Finding 1: GPT-4o Performed Best Overall

GPT-4o achieved the highest overall score.

It performed strongly in:

ROUGE-L
BERTScore
Overall quality

This means GPT-4o preserved meaning and content well.

Finding 2: Gemini Had the Best ROUGE-1

Gemini achieved the highest ROUGE-1 score.

This means Gemini had strong single-word overlap with the reference summaries.

Finding 3: Llama-3 Had the Best ROUGE-2

Llama-3 achieved the highest ROUGE-2 score.

This means it preserved two-word phrase patterns better than other models.

Finding 4: BLEU Scores Were Low

All BLEU scores were low.

This happened because LLM summaries are abstractive and often use different wording from BERT extractive summaries.

Low BLEU does not always mean the summary is bad.

It may simply mean the summary uses different words.

Finding 5: BERTScore Was High for All Models

All models achieved high BERTScore values.

This means that even when exact words differed, the semantic meaning was mostly preserved.

Finding 6: Claude Had Best Sentiment Preservation

Claude had the lowest sentiment shift.

This means Claude changed the original emotional tone the least.

Finding 7: Claude Had the Most Balanced Entity Treatment

Claude had the smallest difference between Modi sentiment and Rahul sentiment.

This suggests Claude treated political entities more neutrally.

Finding 8: DeepSeek Had the Highest Entity Sentiment Difference

DeepSeek showed the largest sentiment difference between Modi and Rahul.

This may indicate stronger political sentiment imbalance.

Finding 9: Quality and Fairness Are Different

The most important finding is:

The best model for summary quality is not necessarily the best model for fairness.

GPT-4o had the best quality.

Claude had the best sentiment preservation and political balance.

Main Conclusion

This project shows that LLM-generated summaries can preserve meaning well, but they may still show differences in sentiment and political fairness.

The main conclusion is:

In political summarization, accuracy alone is not enough.
A model must also preserve neutrality, sentiment, and fair representation.
Limitations

The project has some limitations:

The dataset is only from Reddit.
Reddit users may not represent all Indian voters.
The analysis mainly focuses on English-language content.
Human-written reference summaries were not available.
BERT extractive summaries were used as benchmark summaries.
TextBlob and VADER may not fully understand sarcasm.
Only selected political entities were analyzed.
A single prompt was used for all models.
Proprietary LLM behavior may change with API updates.
Entity sentiment based only on name mentions is a simplified method.
